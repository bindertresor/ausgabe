Bindertresor, Ausgabedateien
Hier liegen die Vorlagendateien des Bindertresor. Das Produkt selbst ist der Leitfaden und liegt nicht hier: https://bindertresor.de

Wer den Leitfaden gekauft hat, bringt damit seine Vorlagendateien auf den neuesten Stand. Sein Vault liest ausgabe.json, vergleicht die Nummer mit der eigenen und holt die Dateien auf Knopfdruck.
