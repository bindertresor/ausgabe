# Bindertresor, Ausgabedateien

Hier liegen die Vorlagendateien des **Bindertresor** — eines Leitfadens für die eigene
Pokémon-Sammlungsverwaltung in Obsidian. Der Leitfaden selbst ist das Produkt und liegt
nicht hier: [bindertresor.de](https://bindertresor.de)

Dieses Verzeichnis hat genau einen Zweck: Wer den Leitfaden gekauft hat, kann seine
Vorlagendateien auf den neuesten Stand bringen. Sein Vault liest die Fassungsdatei,
vergleicht die Nummer mit der eigenen und holt die Dateien auf Knopfdruck. Die Adresse
dafür steht im Leitfaden.

## Was hier liegt

| Datei | Wofür |
|---|---|
| `fassung.json` | Nummer, Datum, was sich geändert hat, und die Liste der Dateien |
| `rahmen.js` | Der gemeinsame Rahmen aller Ansichten |
| `oberflaeche.css` | Die Gestaltung |
| `seite-*.js` | Die einzelnen Ansichten: Start, Dashboard, Album, Sets, Erfolge, Inbox, Karte, Über |
| `preise.py` | Der Preislauf für die Nacht |
